# Employee Directory

A full-stack employee management system built using ASP.NET Core and React.

## Overview

Employee Directory is a modern enterprise application that allows organizations to manage employees, departments, and office locations through a RESTful API and React frontend.

This project is being built as part of my software engineering portfolio to demonstrate enterprise application development using Microsoft's technology stack.

## Technologies

- C#
